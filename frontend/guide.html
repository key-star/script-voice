📱 手机语音配置说明

只需每台手机做一次（约 1 分钟），之后开麦免 AppID

⚠️ 手机必须和电脑连同一个 WiFi。语音数据在局域网内点对点传输，无需流量。

第 0 步：记住这个地址

开麦请用下面的 HTTPS 地址（普通 http 会被浏览器禁掉麦克风）：

__HTTPS_URL__

手机直接点这个链接打不开时，请手动在浏览器输入以上地址（注意是 https 开头）。

第 1 步：下载并安装证书

先用普通 http 地址访问一次（不用装证书也能看）：

__HTTP_URL__

下载 CA 证书：⬇️ 点我下载 ca.crt

第 2 步：安卓安装证书

  • 打开 设置 → 安全 → 加密与凭据（部分机型在「更多安全设置」里）
  • 选 安装证书 → CA 证书，选择刚才下载的 ca.crt
  • 安卓 11+ 还需：进入该证书后，打开「CA 证书用于浏览器/应用」的信任开关

第 2 步：iPhone 安装证书

  • 用 Safari 打开上面的 http 地址，点下载 ca.crt
  • 进 设置 → 已下载的描述文件 → 安装
  • 再进 设置 → 通用 → 关于本机 → 证书信任设置
  • 打开「__LAN_IP__ 的证书」的完全信任开关（这步很多人漏掉）

第 3 步：开麦

打开第 0 步的 HTTPS 地址 → 进入大厅 → 进房 → 点 🎤 上麦 → 浏览器弹出麦克风权限时选允许 → 点「🔊 连接语音」。

绿灯亮起、头像出现🔊 = 可以说话了！
